# 後期3群比較の集計・統計解析

卒業研究の後期調査について、採点の照合、群別の集計、統計検定、図の作成を行うソースです。論文作成時に用いた計算処理を基に、ファイルパスを引数で指定できるようにし、監査結果を集計値と不一致件数だけに絞っています。

このディレクトリに研究参加者の回答ファイルは含めていません。以下の実行には、利用権限のある後期調査のExcelファイルをローカルで用意してください。スクリプトは入力を読み取り専用で開き、参加者ID、日付、自由記述、個別回答を出力しません。日付は実施間隔などの分析に使いません。自由記述は記入有無のみ集計し、論文の記述的な読み取りは自動化していません。

## 実行方法

Python 3.12で検証しました。SciPy 1.16以降が必要です。まず環境を作り、依存パッケージを入れます。

```sh
python -m pip install -r requirements.txt
python audit.py "/path/to/late-study.xlsx" --out-dir results
python plot_results.py results/audit_results.json --output results/late_pre_post.png
```

図の日本語表示には、日本語フォント（游明朝、Noto Sans CJK JP等）が必要です。自動検出できない場合は `--font /path/to/font.ttf` を指定するか、`--language en` で英語ラベルを使用できます。以前の説明ラベル付きファイルとの変更件数も照合するには、`audit.py` に `--prior-workbook /path/to/earlier.xlsx` を追加してください。

## 照合・出力

- `audit.py` は設問正答表と回答コードを照合し、各段階の得点を再計算します。複数選択の回答コードは、入力表の並びと書式に合わせて正答コードに完全一致する場合に正答とします。1週間後の未回答は欠測とし、得点0と区別します。
- 事前・事後の前後比較には対応する7問を使います。個人ごとの改善幅を求め、対応のあるt検定、Welch分散分析、Welchの対比較を行います。対比較のp値は指標ごとの3比較をHolm補正し、95%信頼区間は個別比較の未補正区間です。Hedgesのgおよび、事前得点で調整した補助解析（HC3標準誤差・正規近似）も計算します。
- `audit_results.json`、`word_descriptive.tsv`、`word_pairwise.tsv` を指定ディレクトリに出力します。入力表の保存済み値または参照式と不一致がある場合は、項目別の件数を出力し、終了コード1を返します。
- 集計JSONには、追跡回答者に限定した事後4問と追跡4問の平均・差、および各群の当日完了者に占める事後4問満点の人数・割合も含まれます。事後・追跡の設問は異なるため、同じ回答者にそろえた差も記憶保持率ではありません。
- `plot_results.py` は集計JSONだけを読み、対応7問の事前・事後平均と、各平均の未補正95%信頼区間を描きます。これは個人内の改善幅の信頼区間とは異なります。

入力表のシート名と列の並びは、研究で使用した様式（「参加者一覧」「事前回答」「学習中回答」「事後回答」「1週間後回答」「設問正答表」など）を前提としています。行を並べ替えた表や、対象者数・追跡回答の状況を変更した表で実行する場合は、入力表の保存済み数式・集計も含めて見直してください。
