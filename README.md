# 自転車青切符制度に関する場面判断型Web教材

卒業研究「自転車青切符制度に関する場面判断型Web教材の開発と学習効果の検証」のソースコードです。前期と後期に調査で使った教材，その実装と評価項目，後期の採点・集計・作図を参照できます。

| フォルダー | 内容 |
| --- | --- |
| [early](early) | 前期教材。日本語・英語の画面，学習問題，画像，採点と解説。当時の資料に掲載したApps Scriptの実装例も収録 |
| [late](late) | 後期の3群比較教材。共通評価，群別の表示と解説，割付，ログ，追跡用Google Formsの照合，メール送信処理，テスト |
| [analysis](analysis) | 後期データの採点・集計，群間比較および作図 |
| [tools/qr](tools/qr) | 募集用QRコードの生成処理を任意のURLで動かせる形にしたもの |

各フォルダーのREADMEに元の版と確認手順を記載しています。前期教材と後期教材の画面は手元で確認できます。公開用のコピーでは実運用の送信先と接続情報を空欄または例示値に置き換えています。参加者の回答，連絡先の記録，分析用ワークブックは収録していません。

このリポジトリは卒業論文からソースコードを参照するための資料です。調査の回答受付には使用しません。
